# Живой реестр состояния проекта (Living State Ledger)

## Цель
Автономная мини-утилита **Pura Hotspot** для смартфонов Huawei (Pura 70, EMUI 14.2 / HarmonyOS).
Задача: автоматическое включение мобильной точки доступа при подключении к выбранному Bluetooth-устройству (автомагнитола, наушники) и отключение при разъединении (с задержкой-антидребезгом).

## Результаты полевого тестирования (Field Test Results)
Пользователь протестировал релиз v1.2.0 на реальном смартфоне Huawei Pura 70:
1. **При заблокированном экране**: кликер шторки (Accessibility) не срабатывает (EMUI 14 блокирует доступ к дереву узлов интерфейса через экран блокировки/Keyguard).
2. **При разблокированном экране**: шторка выпадает прямо перед глазами во время использования телефона, сбивает активные действия пользователя и срывается при любом касании экрана.
3. **Вывод**: Любая симуляция интерфейса (Accessibility / клики по шторке или окнам настроек) на практике непригодна для продакшена и раздражает пользователя. Нужен 100% программный запуск без взаимодействия с экраном.

## Реальность платформы Android 14 и EMUI 14
1. **Почему обычный APK не может программно дернуть точку доступа в коде**:
   В Android вызовы `ConnectivityManager.startTethering` / `TetheringManager.startTethering` защищены системным разрешением `android.permission.TETHER_PRIVILEGED` (`protectionLevel="signature|privileged"`). Обычные сторонние приложения принципиально не могут вызвать этот API из Java/Kotlin без падения с `SecurityException`.
2. **Почему в MacroDroid и Tasker точка доступа работает нестабильно**:
   Они сталкиваются с тем же самым: либо костыльно кликают по экрану (что сбивается и бесит), либо требуют Root / Shizuku / ADB.
3. **Единственный 100% программный, бесшумный и надежный способ**:
   Выполнение команды через системный шелл ADB (UID 2000, у которого есть `TETHER_PRIVILEGED`):
   `cmd connectivity start-tethering wifi` (включение) и `cmd connectivity stop-tethering 0` (выключение).
   - Выполняется за 50 мс;
   - Экран вообще не загорается;
   - Никаких всплывающих окон, шторок и прерываний пользователя;
   - Работает в кармане при заблокированном телефоне со 100% надежностью.
4. **Специфика Huawei Pura 70 (EMUI 14)**:
   Huawei удалила из настроек «Отладку по Wi-Fi». Поэтому запустить Shizuku на самом телефоне автономно нельзя. Его нужно активировать подключением по USB к ПК один раз после включения телефона. Служба Shizuku работает в фоне до следующей перезагрузки (неделями).

## Сделано
1. В приложении уже реализована поддержка Shizuku (`ShizukuManager.kt`) и отправка команды `cmd connectivity start-tethering wifi` (`HotspotController.kt`).
2. При наличии прав Shizuku приложение автоматически работает в чистом программном режиме, минуя костыли со шторкой.

## В процессе / Следующий шаг
- Подготовить для пользователя понятную инструкцию и удобный 1-кликовый bat-скрипт для быстрого запуска Shizuku через ПК.
- Дать возможность в приложении полностью отключить режим Accessibility и переключить его строго на бесшумный программный режим Shizuku.

## Грабли (Caveats & Anti-Patterns)
- *Клики по шторке через Accessibility*: на EMUI 14 не работают сквозь заблокированный экран и портят UX при разблокированном. Метод признан тупиковым («шляпа»).
- *Отладка по Wi-Fi на Huawei*: пункт вырезан вендором. Локальный запуск ADB/LADB невозможен без ПК.
